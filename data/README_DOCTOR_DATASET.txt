Doctor dataset import
=====================
1. Sign in with an administrator account.
2. Open Admin > Doctor Management.
3. Choose data/doctors_dataset_all_departments.csv (or the downloaded copy).
4. Click Upload and Import.
5. Review the import summary and any rejected row errors.

Import matches existing users by email and updates their doctor profile, preventing duplicate users on repeat imports. The records are fictional demo data, not verified real doctors. CSV import creates/updates user-service doctor records and does not create authentication credentials/passwords for doctor logins. Existing patient appointment booking uses the imported doctor IDs.
